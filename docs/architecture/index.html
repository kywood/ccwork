4. 시퀀스 — 초기 로딩 / 저장 / 삭제

각 mutation은 API 성공 후에만 로컬 state를 갱신한다. 저장 에러는 Context가 throw하고 NoteEditor.handleSave가 처리한다.

sequenceDiagram
  autonumber
  actor U as 사용자
  participant E as NoteEditor
  participant L as NoteList / NoteItem
  participant C as NotesContext
  participant A as api/notes.ts
  participant S as json-server

  rect rgba(120,120,120,.12)
  Note over C,S: 초기 로딩
  C->>A: fetchNotes()
  A->>S: GET /notes
  S-->>A: Note[]
  A-->>C: Note[]
  C->>C: setNotes · setLoading(false)
  end

  rect rgba(59,130,246,.12)
  Note over U,S: 저장 (새 노트 / 수정)
  U->>E: 저장 클릭
  E->>E: 제목 검증, setSaving(true)
  alt isCreating
    E->>C: addNote(title, content)
    C->>A: createNote()
    A->>S: POST /notes (createdAt, updatedAt)
  else 수정
    E->>C: editNote(id, updates)
    C->>A: updateNote()
    A->>S: PATCH /notes/:id (updatedAt)
  end
  S-->>A: Note
  A-->>C: Note
  C->>C: setNotes(append 또는 map 교체)
  C-->>E: resolve
  E->>E: onDone() → App.setIsCreating(false)
  E->>E: finally setSaving(false)
  end

  rect rgba(220,38,38,.10)
  Note over U,S: 삭제 (확인 없이 즉시)
  U->>L: 삭제 클릭 (stopPropagation)
  L->>C: removeNote(id)
  C->>A: deleteNote(id)
  A->>S: DELETE /notes/:id
  S-->>A: 200
  C->>C: setNotes(filter)
  end

5. 에디터 화면 상태 (UI 상태 머신)

selectedNoteId와 isCreating은 상호 배타적이다. 저장 후 선택은 유지되고 isCreating만 해제된다.

stateDiagram-v2
  [*] --> Empty
  Empty: 비어 있음
  Empty: selectedNoteId=null, isCreating=false
  Editing: 노트 편집
  Editing: selectedNoteId=id, isCreating=false
  Creating: 새 노트
  Creating: selectedNoteId=null, isCreating=true

  Empty --> Editing: onSelect(id)
  Empty --> Creating: onNewNote
  Editing --> Editing: onSelect(다른 id)
  Editing --> Creating: onNewNote
  Creating --> Editing: onSelect(id)
  Creating --> Empty: 취소 (onDone)
  Editing --> Editing: 저장/취소 (onDone)
  Creating --> Creating: 저장 실패
